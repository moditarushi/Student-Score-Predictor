# 🎓 Student Score Prediction System

This project is a Machine Learning web application that predicts a student's exam score based on study habits and lifestyle factors.

---

## 🚀 Features
- Predicts student exam score
- Takes inputs like study hours, sleep, and activities
- Interactive web interface using Streamlit
- Real-time prediction

---

## 🧠 Machine Learning
- Model Used: Linear Regression
- Data preprocessing and feature selection applied
- Model trained on student performance dataset

---

## 🛠 Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

---

## 📊 Inputs
- Study Hours
- Sleep Hours
- Previous Scores
- Other lifestyle factors

---

## 🎯 Output
- Predicted exam score

---

```bash
pip install -r requirements.txt
